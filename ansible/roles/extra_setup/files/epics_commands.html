EPICS commands (from terminal)

Accessing PV values

caget <RECORD_NAME>[.FIELD]
pvget <RECORD_NAME>[.FIELD]

Writing to PV values

caput <RECORD_NAME>[.FIELD]
pvput <RECORD_NAME>[.FIELD]

Connection to IOC shell

socat - unix:/run/ioc@iocdemopvs/control

OR

telnet localhost <port_number>

where <port_number> is found in /run/ioc@iocdemopvs/info

Controlling IOC service

sudo systemctl status ioc@iocdemopvs.service
sudo systemctl stop ioc@iocdemopvs.service
sudo systemctl start ioc@iocdemopvs.service
sudo systemctl restart ioc@iocdemopvs.service
sudo systemctl enable ioc@iocdemopvs.service
sudo systemctl disable ioc@iocdemopvs.service
