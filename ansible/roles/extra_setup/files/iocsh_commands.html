IOC Shell Commands

List Records

dbl [record_type]

If supplied, record_type restricts the list to that type.
e.g., dbl ai

Print Fields of One Record

dbpr name_of_record [interest_level: int]

interest_level, default = 0. Controls the number of fields shown.

Search For Record Name Pattern

dbgrep glob_pattern

Get Field Value

dbgf RECORD_NAME[.FIELD]

Put Field Value

dbpf RECORD_NAME[.FIELD] VALUE
